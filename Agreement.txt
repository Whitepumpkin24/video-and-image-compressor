ABOUT THIS SOFTWARE
Video and Image Compressor is a small hobby project. It was vibe-coded (written with the help of AI) as a PowerShell script that provides a simple window for compressing individual files or batches of videos or images to a target file size per file. Each batch uses shared compression settings and processes files sequentially. Videos are processed by FFmpeg (ffmpeg.exe and ffprobe.exe). For images, you can choose ImageMagick (magick.exe) or CaesiumCLT (caesiumclt.exe). All three are separate open-source programs bundled with this installer.
